# Help: Scoring Rubrics

## 4-Point Scale (Per-Reviewer)

Used for individual review rounds:

| Score | Label | Meaning |
|-------|-------|---------|
| 1/4 | Reject | Major flaws, not suitable for venue |
| 2/4 | Weak Accept | Acceptable with revisions |
| 3/4 | Accept | Good contribution, minor issues |
| 4/4 | Strong Accept | Excellent, must accept |

## Submission Readiness

To advance past recheck:
- **Average** score across all reviewers >= **2.5/4**
- **No individual** reviewer below **2/4**
- At least **5 reviewers** per paper

## 10-Point Scale (Cross-Portfolio)

Used for the cross-portfolio panel ranking:

| Range | Tier | Label |
|-------|------|-------|
| 8.0-10.0 | A | Program Flagship |
| 7.0-8.0 | A- | Strong |
| 6.5-7.0 | B+ | Solid |
| 6.0-6.5 | B | Competent |
| 5.0-6.0 | B- | Needs Work |
| <5.0 | C | Not Ready |

## Consensus Metrics

Measured by standard deviation across reviewer scores:
- **Strong consensus**: σ < 0.5 (reviewers closely agree)
- **Moderate consensus**: σ < 1.0
- **Weak consensus**: σ < 1.5
- **No consensus**: σ >= 1.5 (significant disagreement)

## Verdict Mapping

Text verdicts map to numeric scores:

| Verdict | Score |
|---------|-------|
| Strong Accept | 4.0 |
| Accept | 3.0 |
| Accept with Minor Revisions | 2.5 |
| Weak Accept | 2.0 |
| Major Revisions Required | 1.5 |
| Reject | 1.0 |
