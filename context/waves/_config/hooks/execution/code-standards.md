# Hook: Code Standards

**Stage**: execution
**Type**: checklist
**Required**: false

## Description

Verify code meets project standards before execution review.

## Checklist

- [ ] Code follows project naming conventions
- [ ] Functions have clear, single responsibilities
- [ ] Error handling is consistent with project patterns
- [ ] No commented-out code blocks
- [ ] No TODO/FIXME comments without linked issues
- [ ] Tests written for new functionality

## On Failure

This hook is advisory. Address code standard issues if possible, document any technical debt for follow-up.
